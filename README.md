# Quantitative Finance and Risk Management Projects

A collection of quantitative finance projects completed as part of my coursework. These projects demonstrate applications of risk management, quantitative analysis, portfolio optimization, and time series modeling using Python and R.


| Project | Description | Language | Repository |
|---------|-------------|----------|--------|
| Value at Risk (VaR) Analysis | Estimate market risk using multiple VaR methodologies. | R | https://github.com/tranngocchau281005-byte/VaR-Analysis |
| Moody's KMV Credit Risk Model | Estimate Distance to Default (DD) and Probability of Default (PD). | R | https://github.com/tranngocchau281005-byte/KMV-Credit-Risk-Model |
| Genetic Algorithm Portfolio Optimization | Optimize portfolio allocation using a genetic algorithm. | Python | https://github.com/tranngocchau281005-byte/Genetic-Algorithm |
| ARCH–GARCH Volatility Analysis | Model conditional volatility of stock returns. | Python | https://github.com/tranngocchau281005-byte/ARCH-GARCH-Volatility-Modeling |
| Herding Behavior Analysis | Analyze market herding using rolling CAPM betas and a state-space model. | Python | https://github.com/tranngocchau281005-byte/Herding-Behavior-Analysis |
| Drawdown & Maximum Drawdown | Measure downside risk using drawdown analysis. | Python | https://github.com/tranngocchau281005-byte/Maximum-Drawdown-Analysis |
